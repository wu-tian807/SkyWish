# SkyWish — Cities: Skylines II 本地创作工作台

游戏内模组目前名为 CityDirector，优先由 Codex 通过 MCP 操作。
目标是持续编辑同一座城：摆放和定制资产、编排演员与镜头，并编辑真实运行的公交和地铁。

**已在本机打通外部 Codex → Blender → 游戏资产注册与管理。** 测试长椅成功导入并在游戏中实际摆放，修复后的贴图与材质显示正常；游戏右上角“导入资产库”可查看、隐藏、重新显示、确认删除和禁止新导入。原生菜单支持分类、缩略图与运行时刷新。完整验收范围和仍未完成的跨存档依赖检查见 [验证记录](docs/VALIDATION.md)。

本阶段用法、保存与安全移除边界见 [资产工作流](docs/ASSET_WORKFLOW.md)。`asset-library/` 是用户资产数据，不是可随意清理的缓存。

- `src/harness/` 提供 13 个 MCP 工具，含校验、准备、导入、任务查询、隐藏/恢复，以及原生建造菜单查询和分类。
- 19 项自动检查通过，包括真实 C# ↔ Node 管道通信、MCP STDIO 握手、资产不可覆盖、隐藏保留、真实文件删除、原始目录保护、目录联接拒绝、退出等待、孤立删除任务恢复，以及管理窗口输入监听器的重复开关与清理。
- 项目内便携 .NET SDK、依赖锁文件、编译脚本和 Codex 配置示例已准备好。

0.2.1 增加用户确认的永久删除：只清理导入创建的副本、游戏资源和备份，游戏退出后执行；旧存档引用未知不阻止删除。Agent 原始目录始终保留。新版的部署和实机验证状态见验证记录。

0.3.0 增加原生建造菜单接入：查询实时分类树和分类条目，将导入资产热更新到已有分类，并持久保存。已实测长椅位于“城市美化 → 公园”，缩略图、中文标题、改分类去重、完整重启恢复，以及用户 UI 分类选择。用户也可在“导入资产库”修改分类；详细验收见验证记录。

0.3.1 修复管理窗口的摆放预览残留和输入穿透。打开时退出摆放；窗口内搜索、滚动不会带动地图或点击底层建造菜单；关闭按钮和 Esc 返回游戏。已在本机重启并实测，继续摆放时重新选择资产。

0.3.2 修复清理程序启动路径：校验后从资产库内启动，处理已观察到的安装目录运行时访问失败；同时识别已经停止的清理任务，避免永久显示等待退出。已完成卡住的旧长椅删除，实际删除文件与新路径进程等待测试通过；新版本游戏内完整删除流程仍待复测。

0.3.3 修复原生导入器对 `CD` 文件名前缀的识别，避免忽略模型贴图；增加原生材质绑定检查。已实测新长椅在场景中显示为棕色，消除旧版白色镜面异常。

0.3.4 修复新资产热加入菜单后的缩略图缺失，改用游戏本地 UI 图片通道。已在运行中热加入菜单并确认缩略图即时显示，用户复核正常。

模组已安装到本机游戏用户目录，Codex 已登记 `city_director` MCP；已有聊天是否立即发现工具取决于客户端重载。当前通过独立的标准 MCP 客户端进行链路验收。
